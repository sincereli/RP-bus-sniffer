# 嵌入式通信协议综合分析仪（C 题）需求

> 来源：2026 年“晨电智能杯”嵌入式设计竞赛（高年级组）C 题任务书。
> 本文按赛题原文章节摘录：设计任务、基本要求、扩展要求、参数要求、说明。不含项目背景、参赛注意事项、评分标准，也不含任何实现方案或分析。

## 二、设计任务

本题要求设计一套集成多协议接口的嵌入式通信协议综合分析仪，实现接口数据的记录并通过 USB 接口将数据发回电脑，配合特定上位机进行数据分析和回放，同时也支持实时转发模式，实现 USB 转多接口的功能。

## 三、设计要求

### 1、基本要求

**1.1** 硬件系统：集成主控、IIC 接口 OLED 屏、五向摇杆、MicroSD 卡槽、RTC、电平转换电路、供电/充电保护电路及电池；引出串口/IIC/SPI 复用接口、独立 SWD 调试接口（兼容 3.3V/5V 电平，带有烧录状态指示灯，支持 PY32F003 系列单片机烧录）；PCB 尺寸 ≤50×50mm，完成自主 Layout。

**1.2** 支持 UART、IIC、SPI 三种总线，并实现引脚复用可切换；UART 支持 TTL 电平兼容、波特率等参数可调；IIC/SPI 均支持主机读写外设与从机监听抓包两种模式，兼容 3.3V/5V 电平；总线模式与参数可通过屏幕菜单配置。

**1.3** 脱离上位机可独立工作，支持 UART/IIC/SPI/SWD(RTT) 四类总线数据抓包记录；完整记录各总线协议字段（如串口数据、IIC 地址与应答状态、SPI 时序与对应数据等），数据附带时间戳，按日期自动生成目录与文件，支持对应存储格式；记录过程屏幕实时提示工作状态；掉电不损坏已有日志文件。

**1.4** OLED 滚动显示当前总线类型、运行参数、RTC 时间、SD 卡容量状态；通过五向摇杆完成总线切换、参数修改等操作；支持 SD 卡 `config.txt` 配置文件定义总线参数与默认配置，上电自动加载生效。

**1.5** 通过 USB 与设备通信，实现设备参数配置、串口透传调试、IIC/SPI 总线可视化调试、SWD RTT 数据显示等基础功能。

### 2、扩展要求

**2.1** 实现串口自适应波特率。串口无需预先配置波特率，可自动识别并匹配通信速率，实现无预设数据接收。

**2.2** 脱离上位机，通过摇杆选择 IIC/SPI 总线、设备地址（0x00-0xFF）与寄存器地址（0x00-0xFF），直接读取外设寄存器数值，实现离线硬件调试。

**2.3** 上位机集成多总线协议解析与波形显示功能，可选择对应协议解析总线数据，在界面中实时展示通信波形，实现简易逻辑分析仪能力。

**2.4** 上位机读取 SD 卡历史日志，基于时间戳复现串口数据输出过程，还原设备记录时的通信时序。

**2.5** 鼓励实现更多创新功能。

## 四、参数要求

表 1 参数要求表

| 项目 | 指标 | 说明 |
| :--- | :--- | :--- |
| 串口波特率 | 9600-2Mbps | 最大波特率下不丢包，保存数据对比发送端无差异；进入串口通道后，主动检测波特率，识别正确后自动调整波特率至正确参数 |
| IIC 通信速率 | 400kHz（MAX） | 最大通信速率下不丢包，保存数据对比发送端无差异 |
| SPI 通信速率 | 40MHz（MAX） | 最大通信速率下不丢包，保存数据对比发送端无差异 |
| 离线存储 | 支持 32G 存储，FAT32 格式 | 存储内容无缺失，掉电不丢失 |
| 屏幕显示 | 刷新率 30Hz 以上 | 刷屏无闪烁，显示清晰 |
| 上位机 | 各个功能窗口独立，功能完善 | 实现相关功能，UI 布局合理清晰易于理解 |
| 串口回放 | 依据时间戳实现 1 倍速回放、2 倍速回放、10 倍速回放 | 系统将保存的串口 log 通过上位机的串口助手进行回传，回传倍速可选，回传数据无丢失 |
