# 嵌入式通信协议综合分析仪（C 题）功能清单

> **目标平台**：RP2350A（外置 4MB QSPI Flash、USB FS 12Mbps）；最终作品自主 PCB，开发板仅用于前期验证。
> **关键口径**：自适应波特率为 `P0`（赛题表 1 参数要求）；MicroSD 最大 32GB / FAT32；显示为 I2C OLED；RTC 采用外置芯片 + 备份电池；40MHz SPI 抓包走 PIO/DMA，不做实时全量上传；掉电保护目标为“已 `f_sync` 数据零丢失 + 文件系统可挂载”，表 1 字面“零丢失”需由 hold-up 电容与最后一帧测试保证。
> **优先级**：`P0` 赛题基本要求 / `P1` 赛题扩展要求 / `P2` 创新加分。
> 本文只列待实现功能，不含实现计划、排期与详细方案。

## 项目定位

手持式多协议综合分析仪。脱机模式下完成 UART / I2C / SPI / SWD(RTT) 抓包记录、外设寄存器读写、PY32F003 离线烧录；联机模式下配合上位机完成参数配置、串口透传、I2C/SPI 可视化调试、RTT 显示、协议波形与历史日志 1x/2x/10x 倍速回放。
